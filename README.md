## GitHub Repository Analyzer :
-->  A Python project that uses the GitHub REST API to search for repositories and display useful information such as repository name , full name, URL, and star count

# Features :
> Search GitHub repositories using a custom search term .
> Validate empty user input . 
> Send requests to the GitHub REST API .
> Parse JSON responses .
> Display repository information .
> Show repository star counts .
> Handle searches with no result .

# Technologies Used :

>   Python
>  Requests
>  GitHub REST API
>  JSON

# How To Run :

> Make sure Python is installed.
> Install the requests library.

pip install requests

> Run the program

python3 github_analyzer.py

> Enter a search term when prompted.

--> The program will display information about the repositories returned by GitHub.
